## 📂 Structure

| Folder | Contents |
|---|---|
| 📁 `01-schema/` | Create tables · add constraints (PK/FK/unique/check) · seed data |
| 📁 `02-queries/` | Selection/filters · aggregates · joins · set operators · subqueries · correlated subqueries & CTEs |
| 📁 `03-views-indexes/` | Indexes & views for performance |
| 📁 `04-plsql/` | Cursors & procedures · exception handling · functions · DML procedures with OUT params |
| 📁 `05-triggers/` | Validation · audit · `INSTEAD OF` · payment-sync triggers |
| 📁 `06-java-gui/` | `LendingPlatform.java` — **Java/JDBC** GUI client + `items_table.sql` |
